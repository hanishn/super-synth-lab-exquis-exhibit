# GitHub Action Guard

This repository has a mandatory local `pre-push` hook at `.githooks/pre-push`.

Purpose: prevent TechAssistant or any future agent from pushing, opening remote changes, or otherwise advancing GitHub state without explicit user approval.

Rule:

- Do not run GitHub-mutating commands unless the user explicitly authorizes the exact action.
- `git push` is mechanically blocked unless `SSLI_EXQUIS_GITHUB_ACTION_PASSCODE` matches the one-time challenge printed by the hook.
- A successful push consumes the passcode.

Setup for this checkout:

```powershell
git config core.hooksPath .githooks
```

This has already been applied locally for this working copy.
