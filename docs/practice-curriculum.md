# Practice curriculum

## Design intent

Every family should give a player a distinct skill loop, not a differently named
copy of the same scale. The curriculum is ordered from physical navigation, to
recognizable shapes, to hearing, and finally to musical context:

1. **Technique** builds reliable Exquis motion: scalar direction, turns,
   returns, thirds, triad outlines, and overlapping three-note patterns.
2. **Shapes** makes interval and triad geometry reusable: thirds, fifths,
   sixths, and all four basic triad qualities.
3. **Ear training** asks for a heard interval to be reproduced as an exact,
   simultaneous Exquis grip. Targets remain concealed until the player answers.
4. **Repertoire** applies the vocabulary as named forms with sections, tempo,
   count-in, and loop mastery.

## Evidence informing the scope

The breadth mirrors established keyboard/theory exercise taxonomies: keyboard
note, interval, scale, and chord work; interval ear training; and progressive
difficulty/configuration. It does not claim those sources endorse this exact
instrument mapping.

- [musictheory.net exercise catalog](https://www.musictheory.net/exercises)
- [musictheory.net interval-ear-training options](https://www.musictheory.net/exercises/ear-interval)
- [musictheory.net exercise customizer](https://2012.musictheory.net/exercises/customizer)

## Engineering contract

- Exercise events continue to pass the existing target, timing, fingering, and
  playability validation.
- All input surfaces route to the same scoring contract.
- Ear prompts conceal notation targets but preserve exact two-note grip scoring.
- New technique patterns transform the canonical playable scale path; they do
  not invent virtual pads or bypass ergonomic path selection.
- Fixed shape fixtures use the same harmonic grip builder as progression work.
